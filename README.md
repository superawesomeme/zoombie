# Zoombie Racing Simulator

**Version 1.0 – Halloween Edition with 3D GLB Monster Models**

Developed for Picket Piece Social Club, **Zoombie Racing Simulator** is a real-time 3D monster racing broadcast simulation powered by Three.js (r128) and WebGL. Features include eight articulated 3D monster racers, a moonlit haunted highway, spooky atmospheric fog, gravestones, roadside jack-o'-lanterns, live telemetry tracking, broadcast leaderboard, and custom event management.

---

## What Changed in this Upgrade

The eight racers were previously constructed from visibly blocky primitive cubes and boxes inside runtime JavaScript. This upgrade replaces them with **eight polished, lightweight, stylised 3D monster models** supplied as local, self-contained binary GLB files:

1. **Vampire** – Red racer; pale stylised face, swept widow's-peak hair, small fangs, high collar, dark suit, and flowing red-lined cape.
2. **Pumpkin Fiend** – Orange racer; rounded ridged pumpkin head, carved glowing face, crooked stem, and vine tendril details.
3. **Cursed Mummy** – Yellow racer; rounded wrapped body and head, layered bandage rings, dark gaps, and loose trailing bandage strips.
4. **Franken-Zombie** – Green racer; broad head and shoulders, heavy brow, dark hair slab, metallic neck bolts with hex heads, and classic outstretched shambling arms.
5. **Spectral Banshee** – Blue racer; eerie elongated face, hollow glowing eyes, flowing hair tendrils, and semi-transparent ethereal veil lower body floating above the road.
6. **Witch-Imp** – Purple racer; expressive rounded face, crooked pointed witch hat with brim and band, pointed ears, crooked nose, and short cape.
7. **Werewolf** – Dark grey racer; heavy brow, pronounced wolf snout and nose, pointed ears with inner ear detail, glowing eyes, fangs, fur back spikes, and curved tail with fluffy tip.
8. **Skeleton** – Off-white racer; clear skull dome, cheekbones, jaw line, hollow eye sockets, nasal cavity, teeth, spine, ribcage, pelvis bowl, and rounded limb bones with ball joints.

### Architecture & Engineering Highlights
* **Zero External Dependencies / No Blender Required**: All 8 GLB files are generated by a reproducible Node.js pipeline (`tools/generate-monsters.mjs`) that builds binary GLB (glTF 2.0) files directly using standard Node.js without requiring Blender, external modeling tools, npm packages, or cloud APIs.
* **Standard Rig Node Hierarchy**: Each GLB embeds standard named transform nodes (`Root`, `Body`, `Head`, `Arm_L`, `Arm_R`, `Leg_L`, `Leg_R`, `Extra`). The application's procedural animation system finds these nodes at runtime, preserving articulated running, shambling, floating, and celebration cycles.
* **Model Manager (`MonsterModelManager`)**: Preloads all 8 GLB assets before enabling the start button, displays a loading progress indicator (`Loading racers… X/8`), caches source models, deep-clones them for each race, and cleanly disposes per-race resources on restart.
* **Automatic Procedural Fallback**: If any GLB fails to load or is missing, the application automatically falls back to the procedural monster model for that specific lane without interrupting the race.

## Running Locally

Because the application loads local `.glb` binary models via fetch/XHR, a local web server is required to satisfy browser CORS policies:

### Using the Included Zero-Dependency Node.js Server
```bash
node tools/serve.mjs
```
Then navigate to: `http://localhost:8000/`

*(Alternatively, any standard static server works: `npx serve .`, `python -m http.server 8000`, or VS Code Live Server).*

---

## Regenerating the 3D Monster Models

To reproduce or regenerate all 8 GLB binary files from scratch:

```bash
node tools/generate-monsters.mjs
```

This will run the deterministic generator and output the 8 binary GLB files directly into `models/`.

### Verifying Model Structure
To validate that all 8 GLBs contain required headers, glTF 2.0 chunks, and rig nodes:

```bash
node tools/validate-monsters.mjs
```

### Running Automated Browser Verification Tests
An end-to-end headless browser test suite is included in `tools/browser-test.mjs`:

```bash
# In terminal 1 (start server):
node tools/serve.mjs

# In terminal 2 (run tests):
node tools/browser-test.mjs
```

The test runner launches headless Microsoft Edge via Chrome DevTools Protocol (CDP), tests all 8 GLBs in `tools/test-suite.html`, runs `index.html`, completes an entire race, tests winner celebrations, restarts, and verifies custom event management.

## Usage

### Starting a Race
1. Select a race from the dropdown menu (e.g. *Walworth Werewolf Dash*, *Hellhound Highway*).
2. The preview grid will display the 8 participating monsters and their assigned numbers and colors.
3. Once racers are preloaded, click **"RACE!"** to start the 3-second spooky countdown.
4. Watch the monsters race down the haunted highway with live broadcast telemetry, positions, and dynamic camera angles.
5. When the winner crosses the finish line, celebrate with Halloween fireworks and official results!
6. Click **"NEXT RACE"** to immediately roll to the next event.

### Creating Custom Races
1. Click the **"MANAGE"** button on the start screen.
2. Enter custom names for each of the 8 monsters.
3. Enter an Event Name (e.g., *Halloween All-Stars Final*) and click **"SAVE EVENT"**.
4. Custom events are persisted in browser `localStorage`.
5. To restore defaults, click **"Reset all data to defaults"** in the management modal.

## Technology Stack

* **Rendering Engine:** Three.js (r128) with PCFSoftShadowMap
* **Model Format:** Binary glTF (GLB 2.0) with PBR materials and emissive accents
* **Audio:** Web Audio Horrific Synth Engine + looped ambient audio
* **Fonts:** Creepster, Rajdhani, Roboto Condensed
* **Compatibility:** Compatible with all modern desktop and mobile browsers, zero build step, 100% static hosting on GitHub Pages.
